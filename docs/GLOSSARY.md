# อภิธานศัพท์

เรียงตามตัวอักษรภาษาอังกฤษ

| ศัพท์ | ความหมาย |
|---|---|
| **A/B match** | การแข่งระหว่าง engine ที่ใช้ net ใหม่กับ net เดิม เพื่อตัดสินว่าควรรับ net หรือไม่ ดู [EVALUATION.md](EVALUATION.md) |
| **accumulator** | ผลรวมน้ำหนักชั้นแรกของ NNUE ณ ตำแหน่งปัจจุบัน แบบ incremental จะปรับค่าเฉพาะส่วนที่หมากเปลี่ยน |
| **alpha-beta** | เทคนิคตัดกิ่งของการค้นหา ทำให้ไม่ต้องพิจารณาตาเดินที่ไม่มีทางถูกเลือก |
| **batch / superbatch** | batch คือข้อมูลก้อนหนึ่ง (16,384 ตำแหน่ง) ที่ปรับน้ำหนักหนึ่งครั้ง superbatch คือชุดของ batch ที่บันทึก checkpoint หนึ่งครั้ง |
| **bullet** | ไลบรารีเทรน NNUE ที่โครงการใช้ ตรึงที่ git rev (D-002) |
| **centipawn (cp)** | หน่วยคะแนน 100 cp เท่ากับได้เปรียบเบี้ยหนึ่งตัว |
| **checkpoint** | สถานะการเทรน ณ จุดหนึ่ง เก็บใน `checkpoints/` (ไม่เข้า git) |
| **cozy-chess** | ไลบรารีสร้างตาเดินที่ถูกกติกา (D-004) |
| **datagen** | โปรแกรมสร้างข้อมูลเทรนด้วย self-play |
| **Elo** | หน่วยวัดความต่างของความแรงจากผลแข่ง ค่า 0 หมายถึงเท่ากัน |
| **error bar (±)** | ช่วงความคลาดเคลื่อนของ Elo ที่วัดได้ ยิ่งแข่งมากเกมยิ่งแคบ |
| **FEN** | ข้อความมาตรฐานที่ใช้อธิบายตำแหน่งบนกระดาน |
| **fastchess** | โปรแกรมจัดการแข่งระหว่าง engine ที่ใช้ในการทดสอบ A/B |
| **iterative deepening** | ค้นหาทีละความลึก 1, 2, 3 ... เพื่อให้มีผลที่ใช้ได้เสมอเมื่อหมด node |
| **loss** | ค่าความผิดพลาดของ net ต่อเฉลย ยิ่งน้อยยิ่งทายใกล้เคียง **เปรียบเทียบข้ามชุดข้อมูลไม่ได้** |
| **negamax** | รูปแบบเขียน minimax ที่ใช้ฟังก์ชันเดียวสำหรับทั้งสองฝ่าย |
| **net** | ไฟล์น้ำหนักของ NNUE ที่ผ่านการเทรน (`nets/*.bin`) |
| **NNUE** | Efficiently Updatable Neural Network เครือข่ายขนาดเล็กที่คำนวณใหม่ได้เร็วเมื่อหมากขยับเพียงเล็กน้อย |
| **node / node limit** | node คือตำแหน่งหนึ่งที่การค้นหาพิจารณา node limit คือจำนวนสูงสุดต่อตาเดิน ใช้ควบคุมความแรง |
| **NTM / STM** | ฝ่ายที่ไม่ถึงตา (not to move) / ฝ่ายที่ถึงตา (side to move) |
| **quantisation** | การปัดน้ำหนักทศนิยมเป็นจำนวนเต็ม (int16) เพื่อลดขนาดและคำนวณบนไมโครคอนโทรลเลอร์ได้ |
| **quiescence search** | การค้นหาต่อเฉพาะตาเดินที่รุนแรง (เช่น การกิน) จนตำแหน่งสงบ ก่อนประเมิน |
| **round (รอบ)** | หนึ่งรอบของวงวน: สร้างข้อมูล → เทรน → แข่ง A/B |
| **screlu** | ฟังก์ชันกระตุ้น `clamp(x, 0, QA)²` |
| **self-play** | ให้ engine เล่นกับตัวเองเพื่อสร้างข้อมูล |
| **UCI** | Universal Chess Interface โปรโตคอลที่โปรแกรมหมากรุกใช้สื่อสารกัน |
| **wdl** | น้ำหนักที่ให้ผลแพ้/เสมอ/ชนะจริงในเฉลยตอนเทรน (0.0 = ใช้คะแนนของ engine ล้วน) ใช้ 0.0 ตาม D-010 |
