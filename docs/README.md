# เอกสารโครงการ Wyrdmate

ดัชนีของเอกสารทั้งหมดในโฟลเดอร์ `docs/` เลือกอ่านตามวัตถุประสงค์ของท่าน

| ต้องการ | อ่าน |
|---|---|
| เข้าใจวิธีที่ engine เลือกตาเดิน | [SEARCH.md](SEARCH.md) |
| เข้าใจภาพรวมและการออกแบบระบบ | [ARCHITECTURE.md](ARCHITECTURE.md) |
| รู้ว่าแต่ละไฟล์ทำหน้าที่อะไร | [STRUCTURE.md](STRUCTURE.md) |

| ทดสอบและตัดสินว่า net ใหม่แรงกว่าเดิมหรือไม่ | [EVALUATION.md](EVALUATION.md) |

| [EVALUATION.md](EVALUATION.md) | วิธีแข่ง A/B เกณฑ์การรับ net และการบันทึกผล | ผู้เทรน |

## หมายเหตุเรื่องเอกสารอื่นนอกโฟลเดอร์นี้

- [`../README.md`](../README.md): หน้าแรกของ repository (ภาษาอังกฤษ)
- [`../CLAUDE.md`](../CLAUDE.md): คู่มือและกฎเหล็กของโครงการ ซึ่งผู้ช่วย AI อ่านโดยอัตโนมัติ
  ถือเป็นแหล่งอ้างอิงหลักของกฎ หากเอกสารใดขัดแย้งกับไฟล์นี้ ให้ยึด `CLAUDE.md`

## แนวทางการเขียนเอกสาร

- เอกสารสำหรับผู้อ่านเขียนเป็นภาษาไทยแบบทางการ คงศัพท์เทคนิคเป็นภาษาอังกฤษ
- ตัวเลขผลการทดลองต้องระบุจำนวนเกมและช่วงความคลาดเคลื่อน และต้องตรงกับ `nets/RECORDS.md`
- การตัดสินใจที่เปลี่ยนแปลงให้เพิ่มรายการ D-xxx ใหม่ใน `decisions.md` ห้ามแก้รายการเดิม
- เพิ่มไฟล์ใหม่ในโครงการแล้ว ให้อัปเดต `STRUCTURE.md` และตารางในไฟล์นี้
